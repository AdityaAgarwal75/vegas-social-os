# ChatGPT workstation workflow

Read the repository docs/CHATGPT-FIRST.md and docs/NEW-USER-JOURNEY.md when planning setup or automation. Treat ChatGPT as the creative workstation and the dashboard as sign-in/storyboard/clip/release review. Do not direct the owner to manual generation forms.

Start with guide/doctor/account_list/onboarding_status. For feedback call review_queue, consume awaiting_agent items, read original plan, research/rewrite using owner feedback, save a new same-channel plan using `review:<request-id>` as stable request_id, and call review_complete with the new plan ID. Preserve original media/jobs; new revisions require new selection/image approval and release review. A queued feedback item is not a running agent.

For approvals reload plan/images/assets/budget and inspect live Flow settings before video_request. Approval permits only that creative and ceiling; exact social release approval remains separate until a real persisted auto-release policy is implemented. Use stable jobs and reconcile unknown outcomes.

Two daily concepts do not equal two videos. Prepare two distinct productions if two videos are requested. Before unattended keyframes, verify whether owner authorized agent concept selection; otherwise show ideas for selection first. Current tool model attaches images to the selected concept only.

MCP events are the selected design for host continuation, not available in this server yet. Host support requires Work/event permissions, MCP 2.0, a verified subscription and signed callbacks. Never claim schedule_daily or images_approve wakes ChatGPT. Report Waiting for ChatGPT until there is a real run. Verify actual native tool/byte handoff in that host; no silent API fallback.

Installations are private and independent. AWS Core/SSM bootstraps before Social OS exists. Packaging does not equal installed/consented plugin. Optional host Drive consent does not transfer its token to the VPS. Current Social OS endpoint does not provide arbitrary root shell; use the owner's authorized infrastructure connector for admin work until the scoped broker is implemented.
