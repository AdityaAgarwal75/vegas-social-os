# Agent setup contract

Read root `BOOTSTRAP.md` and `agent-manifest.json` when the repository itself is available. In a remote skill-only package, use this reference to find the entrypoint at:
https://github.com/AdityaAgarwal75/vegas-social-os/blob/main/BOOTSTRAP.md

Own technical setup when a connected VPS tool exists. Users authorize accounts/costs, enter dashboard profiles, complete Google/Meta login/2FA/plugin consent, and approve creative work. When no remote agent access exists, the documented open-source VPS bootstrap is a supported self-service route. Never request credentials or secrets in chat.

Discover actual source read, VPS control/process execution, private persistent volume, HTTPS and plugin-creation tools. Prefer independently hosted Ubuntu/Debian VPS + SQLite through scripts/bootstrap-ubuntu.sh or scripts/install-vps.sh. Use `setup_plan` capability vps_manage when verified. No Supabase or Render is required. Managed cloud remains optional, with paid resources requiring consent; do not make it the default. Native images and asset transfer are separate creative-stage requirements.

Provision one isolated user-owned VPS service/account/data directory; never reuse maintainer infrastructure, credentials, or unrelated apps. SQLite is local authoritative state and encrypted credential storage uses a vault key in a private directory. Both data and key must survive restart. The optional cloud Supabase revision-checked RPC belongs only to managed-cloud mode; its outages must block cloud writes.

Provision the sandboxed graphical Chromium/noVNC runtime. VNC/CDP stay loopback-only; account-specific login tickets/cookies authorize the browser stream. Verify unauthorized and cross-account denial. No everyday browser-cookie extraction. Real Google security/consent checks remain required.

Configure Google/Meta developer apps through permitted connected tools. If tools/approval are missing, surface the exact connection/approval gap. A developer app is still necessary; logging into Google does not create official Flow OAuth access.

After the verified HTTPS endpoint works, create one remote master plugin through a supported host tool when available, using this particular owner's /mcp endpoint, and present installation consent UI. Verify real read-only plugin calls and save an evidence-based setup receipt. Archive creation alone is not installation or deployment.

Return the clean dashboard URL and short-lived private onboarding link. Users connect accounts in the dashboard; all creative generation/approvals remain in ChatGPT. Missing host-native image bytes is a blocker, not a reason to shift manual uploads onto users. Do not promise an unattended morning pipeline without a real connected scheduler.
