# Content engine 0.13

## Recipes that contain actual prompts

The old 16-card camera-setting catalog is replaced by 35 original recipes with 65 shot prompts. Camera moves, visual effects, product/fashion, UGC, emotional stories, explainers, tutorials, travel, documentary and devotional formats are represented. Cards have no repeated thumbnails. Full prompts are readable before selection. Each recipe states reference requirements, first frame, action, camera movement, timing, end state, continuity, audio and common failures. Multi-shot formats return separate scene image/video prompts and must be rendered separately. Personalization supports exact editable per-shot text. Immutable saved selections retain that text after reload. Old IDs resolve for compatibility without remaining in the gallery.

These are original model-agnostic recipes informed by public/licensed craft, not exports of private Higgsfield presets. A prompt is not a guaranteed native effect control. Actual model, duration, references and quote must be verified before rendering. Default production remains native ChatGPT keyframes plus existing Flow tools. No paid provider operation is added.

Metadata remains untrusted; verify primary sources before making factual claims. Directory-only services are explicitly marked. ## Persistent learning contract

Eight tools add content_context, content_memory_save, learning_policy, performance_capture, performance_observe, learning_lesson_save, research_sources and research_search. The main master skill consumes these through references/content-cycle.md. Existing analytics_summary also exposes learning context for clients with stale tool discovery. Reconnect/refresh tool discovery if the client still caches the previous 126-tool list; the server advertises 134 tools.

Creative memory contains the exact hook, visual hook, formula/family, script, image/video prompts, template IDs, reference IDs, edit/audio plan, duration/aspect, hypothesis and primary metric when supplied. publish_prepare freezes the selected concept, latest channel/project creative record, saved recipe selections, safe job prompt fields and final asset checksum/type/size. Historical missing decisions are labeled missing, never reconstructed. Immutable records live in the installation's existing private SQLite storage.

The read-only observer defaults off for independent installs. Enabling applies only to confirmed public local releases and existing account grants. A separate thread considers baseline plus 6/24/72/168-hour windows, at most one post per five-minute tick, with one-hour attempt cooldown. Checkpoint IDs persist across restart. Missed windows are skipped. Unknown/failed observations cannot resubmit or regenerate content. Server downtime means no observations during that time; an enabled policy does not keep a stopped VPS running.

[YouTube videos.list](https://developers.google.com/youtube/v3/docs/videos/list) validates the connected channel ID and reads actual public counts/publication time/privacy. It does not provide audience retention; [YouTube Analytics metrics](https://developers.google.com/youtube/analytics/metrics) require a separate authorized integration or owner evidence. Instagram basic media counts are separate from Insights; Insights is attempted only when actual stored scopes include the matching permission. Missing grants remain unavailable. Facebook currently records identity/time metadata without invented counts. Owner-supplied metrics require source/time and remain explicitly unverified, excluded from automatic baselines. No new OAuth scope or account permission is requested silently.

Automatic comparisons require five other distinct provider-verified public releases with the same account, publication-age checkpoint, format, duration bucket and aspect. Leave-one-out peer medians are descriptive. Views alone do not identify a hook problem or cause. Shorts starts/replays are not engaged views. The ChatGPT host reviews actual evidence, records an evidence-linked hypothesis and one next test, and retrieves it next time. Reviews wait for a real host session; the VPS does not independently summon ChatGPT/native images, train model weights or rewrite system instructions.
