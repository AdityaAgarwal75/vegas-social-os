# Setup for a community user

Give your capable ChatGPT/Codex agent **https://github.com/AdityaAgarwal75/vegas-social-os** and ask it to install an independent instance in your own AWS account or existing Ubuntu VPS. The agent reads BOOTSTRAP.md and docs/AWS-ONBOARDING.md, discovers its actual tools, quotes billable infrastructure, and executes authorized setup. GitHub stores source; SQLite and media stay on your VPS. Render and Supabase are not required.

The intended user experience is a private dashboard link after provisioning, without terminal work when a connected agent has the necessary execution tools. Tool availability/permissions can differ between ChatGPT accounts; the project cannot grant an unavailable connector AWS permissions. Self-service shell installation remains an alternative for users without an execution agent.

## In your dashboard

1. Open the private one-use pairing link within ten minutes. It establishes an eight-hour owner session. A new link can be generated by your connected setup agent; never post it publicly.
2. Save your profile, brand, goals and timezone in **Setup guide**.
3. In **Connections**, open each provider's app setup guide. It shows official developer-console links, exact OAuth callback URLs, required scopes, privacy/data-deletion links and encrypted app settings. Register your own applications; no shared maintainer credentials are included.
4. Add as many saved Flow accounts as your storage permits. Each gets an isolated profile. Sign in/complete 2FA directly in the embedded Google browser, open a Flow project and verify its workspace. Account count is not a promise of concurrent browser capacity.
5. Connect YouTube/Brand channels, Instagram Business/Creator accounts, Facebook Pages and optional Drive. Provider consent may open its official page and return to this installation. A Flow login is separate from YouTube publishing permission. Missing scopes/app access/eligibility must be resolved with the provider; no consent button bypasses App Review.
6. Save a channel brief with its exact publishing identities. Connect your installation's **/mcp** endpoint to a supported host agent through that host's consent flow. Test read-only tools.
7. Ask the agent to research your audience and save two original ideas, scripts and scene prompts. Review in **Productions**. Native image bytes must be transferred for real; image prompts do not count as files.
8. Review keyframes, set explicit Flow credit ceilings, verify model/one-output settings in the private browser and request one scene at a time. Unknown results stop for inspection. Downloaded clips or an edited final video appear in **Media library**.
9. In **Create a post**, select ordered media, destination, copy, audience and supported cover. Review each exact release in **Release queue**, then approve immediate publishing or its exact schedule. Connection alone never posts.
10. In **Automation**, set daily brief time/channels and connect a real host trigger to consume briefs. The in-app scheduler can publish already approved releases while the server runs; native creative work needs the agent. A server offline for more than an hour after a release time marks it missed instead of publishing stale content.

The repository is an alpha. See docs/STATUS.md for observed tests and remaining provider verification. Use docs/PLATFORM-PERMISSIONS.md for registrations and supported media.
